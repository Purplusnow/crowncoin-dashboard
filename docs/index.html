국가별 — 요청 10회 미만은 기타로 묶습니다(비율이 요동쳐서)

수치는 GA4 → BigQuery 원본에서 하루 2회(인게임·가입자) · 매시 4회(실시간) 수집합니다. 확정 일별 테이블뿐 아니라 스트리밍(intraday)까지 읽어 오늘치가 바로 보입니다 — 아직 확정 안 된 값은 “+”(하한) 또는 집계중으로 표시합니다. 날짜는 모두 KST 기준이고, 각 화면 상단의 갱신 시각이 자동 수집이 살아 있는지를 말해 줍니다 — 시각이 멈춰 있으면 숫자가 아니라 수집을 먼저 의심하세요. 지역·기기모델이 비어 있는 줄(Play 사전 출시 보고서 봇)과 디버그 빌드는 분모에서 제외합니다.

마케팅비는 자동으로 수집되고 인앱매출은 손으로 넣습니다 — Play 는 주문 목록 API 를 주지 않습니다(tools/add.py). ⏸ AdMob 광고매출 금액은 보류입니다 — 계정 전체는 통합 대시보드(SECONDACT BOARD)가 봅니다. 광고 탭의 노출·시청자·완료율은 GA4 에서 오므로 지금도 나옵니다. 각국 통화는 그날 ECB 환율로 원화 환산합니다(주말·공휴일은 직전 영업일). 상단의 인앱 수수료 반영은 인앱매출에서 표시가에 포함된 부가세(config.json 의 tax_rates)와 스토어 수수료 15%를 뗄지를 정하며, 히어로·타일·차트·원장에 한꺼번에 걸립니다.

⚠ 전체 가입자·이상징후는 전 이력을 윈도우 없이 훑습니다 — 앱이 나이를 먹을수록 스캔량이 계속 늘어납니다(원작 실측 8.2GB/회). 지금은 가입자 10MB · 이상징후 60MB 로 무료 구간(월 1TB)의 1% 미만이지만, 각 화면이 스캔량을 스스로 보고하므로 그 숫자가 커지면 윈도우를 다시 설계하세요.
